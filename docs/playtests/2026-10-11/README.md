# Playtest 2026-10-11

Jb's first playtest, with an AI partner over MCP, on v0.5.0 (standard difficulty). About 75 commands, all in the start town's temple (forecourt, hall, chapel).

- `transcript.md`: every command and the game's text, verbatim. The replies' `state` objects are left out; S06 removes them from the player build.
- `save.txt`: the sealed save from the end of the session, for reproducing it with the developer tools.
- `field-notes.html`: the notes page the partner kept during play, at Jb's direction: a pannable map of places and objects, places, texts with grouped sign labels, a sign list, open questions, and a log.

What it showed is in `docs/LOG.md` (2026-10-11) and `docs/milestones/S06-what-the-game-shows.md`.

The field notes are also the first real example of the evidence a player collects, and how they organise it. Read them before designing X01, the record-keeping extension (`docs/milestones/X01-record-keeping-extension.md`). Note that this map was drawn partly from `state` data a person wouldn't have had.
