# S02 samples: notes

Before, each sign was a stroke recipe ("an angular sign, a wedge turned left"); after, a shape ("a squarish, angular sign, with a crossing above", "a tall, mixed sign like a fish-hook"), and most signs need only their proportions, curves and a resemblance or one part to be told apart.
Signs that differ only finely get one more feature, the one that separates them ("leaning back", "sitting low"); the example wording strings these together plainly and Jb's wording will decide how they read.
