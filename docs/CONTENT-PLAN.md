# Content plan

What to write first, by how much play it touches. Made by `scraped-lang content plan --count 10`: the explorer and the scholar play seeds 1–10 (the scholar for a season), and every response they cause is counted by slot family. Write from the top: a family high in the list is met many times an hour, so each variant there is read often and a missing one shows at once. Re-run it after a writing session to see the next most-seen gaps; the authoring tool's Gaps mode shows the same per slot.

How to read it:

- **Seen per hour**: how often, per hour of game time, a response draws on the family (the scholar's long season weighs heavily, so read it as an order, not a rate a player will meet).
- **Still example text**: of those, how many still come from an example variant (all of them, until you write).
- **Variants written / needed**: your own variants against the minimum each slot needs (two each).
- **Slots no bot reached**: slots in the family that no run met; write these last (they are rare, or they wait on late-game play).
