# The cultural lexicon (D07): concepts beyond the starter list, by
# semantic field. A language names every concept in the core fields, and
# those of the fields its culture cares about (see `Culture`); species are
# named only where they live.
#
# One concept per line:  id | pos | field | tags | extras
#   pos      noun verb adj adv det particle
#   field    the semantic field (core fields: body, kin, land, nature, sky,
#            weather, time, act, quality, number-free)
#   tags     nouns: semantic tags; verbs: tags an object must carry (empty:
#            intransitive); adjectives: tags a noun must carry
#   extras   kind=X (a kind of X), part=X (part of X), opp=X (opposite of
#            X), pl=… past=… s=… (English forms where the rule fails)
#
# New words carry their own tags, not the starter list's text tags (good,
# made, place, title, kin, deity), so older texts keep their words until
# D08 writes the genres that use these.
